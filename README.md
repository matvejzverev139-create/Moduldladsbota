# VoiceModule — приватные голосовые комнаты

Модуль для Discord-бота на **JDA 6** (Java 21). Меню управления сделано на **Components V2**.

---

## 1. Что умеет

**Комнаты**
- Человек заходит в войс-создатель → бот создаёт личную комнату с его ником и переносит его туда
- Когда в комнате никого не осталось, она удаляется
- Если владелец вышел, а люди остались, владение автоматически переходит к первому из оставшихся

**Панель управления** (в текстовом канале, кнопки работают для той комнаты, где сидит нажавший)
| Кнопка | Действие |
|---|---|
| ✏️ Название | Переименовать комнату |
| 👥 Лимит | Лимит участников (0 = без лимита) |
| 🔒 Закрыть/Открыть | Запретить/разрешить вход всем |
| 👁️ Скрыть/Показать | Скрыть комнату из списка каналов |
| ➕ Пригласить | Выдать человеку доступ (работает даже если комната закрыта/скрыта) |
| ➖ Забрать доступ | Отозвать выданный доступ. Если комната закрыта/скрыта, человек вылетает и не может зайти обратно |
| ⛔ Бан / ✅ Разбан | Запретить/вернуть вход конкретному человеку |
| 👢 Кикнуть | Выгнать человека из комнаты |
| 👑 Передать | Передать владение. У прежнего владельца снимаются права владельца и личный доступ |

Все кнопки доступны только владельцу комнаты.

**Команда `/setupvoice`** (только администраторы)
- Канал, где будет панель
- Войс-создатель
- Роль, которой доступно меню (если не выбрана, меню доступно всем)
- Баннер для панели
- Кнопка «Опубликовать панель»

## 2. Требования

- Java **21** (JDK, например Temurin с adoptium.net)
- Maven (для сборки)
- Бот-приложение на https://discord.com/developers/applications

---

## 3. Создание бота в Discord

1. https://discord.com/developers/applications → **New Application**
2. Раздел **Bot** → **Reset Token** → скопировать токен (**никому не показывать и не коммитить**)
3. Раздел **OAuth2 → URL Generator**:
   - Scopes: `bot` и `applications.commands`
   - Bot Permissions: `Manage Channels`, `Manage Roles`, `Move Members`, `View Channel`, `Send Messages`
4. Открыть сгенерированную ссылку и добавить бота на сервер
5. Роль бота на сервере должна стоять **выше** обычных участников

---

## 4. Подключение модуля в свой бот

```java
JDABuilder.createDefault(token)
    .enableIntents(GatewayIntent.GUILD_VOICE_STATES)
    .enableCache(CacheFlag.VOICE_STATE)
    .setMemberCachePolicy(MemberCachePolicy.VOICE)   // или ALL
    .addEventListeners(new VoiceModule())
    .build();
```

Файл модуля: `src/main/java/VoiceModule.java` (без пакета; при необходимости добавь свой `package`).
Команда `/setupvoice` регистрируется модулем сама, отдельно ничего делать не нужно.

---

## 5. Запуск как отдельного бота (для теста)

Токен берётся из переменной окружения, в код его не вписывать.

Linux / macOS / Termux:
```
export BOT_TOKEN="токен"
mvn package
java -jar target/voicebot-1.0.jar
```

Windows (PowerShell):
```
$env:BOT_TOKEN="токен"
mvn package
java -jar target/voicebot-1.0.jar
```

IntelliJ IDEA: Run → Edit Configurations → Environment variables → `BOT_TOKEN=токен`.

## 6. Первая настройка на сервере

1. Создай категорию, в ней войс-канал (это будет «создатель») и текстовый канал для панели
2. Напиши `/setupvoice` (нужны права администратора)
3. В меню выбери: канал для панели, войс-создатель, роль
4. Баннер (по желанию): вызови `/setupvoice` и прикрепи картинку в поле `banner` (png/jpg/gif/webp, до 8 МБ)
5. Нажми **«Опубликовать панель»**. После любых изменений публикуй панель заново

Новые комнаты создаются в той же категории, где стоит войс-создатель.

---

## 7. Хранение данных

- Настройки сервера и баннер лежат в папке `data/` рядом с ботом (`data/voice-config.properties`, `data/banner-<id>.<ext>`)
- Папку `data/` нельзя коммитить в git (она в `.gitignore`)
- **Владельцы комнат хранятся только в памяти** (`Map owners`) и сбрасываются при перезапуске бота. Для продакшена рекомендуется заменить на БД

## 8. Частые проблемы

| Проблема | Решение |
|---|---|
| Нет команды `/setupvoice` | Бот добавлен без scope `applications.commands`: добавь заново по ссылке из п. 3. Нужны права администратора. Перезапусти приложение Discord |
| Комнаты не создаются / не переносят | Проверь права бота (`Manage Channels`, `Move Members`) и что роль бота выше участников |
| Бот не видит, кто в войсе | Не включены `GUILD_VOICE_STATES`, `CacheFlag.VOICE_STATE` или `MemberCachePolicy.VOICE` |
| `Unknown interaction` (10062) | Бот не успел ответить за 3 сек (медленное устройство). В модуле команда подтверждается сразу, обнови до этой версии |
| Ошибки компиляции с `net.dv8tion.jda.api.components.*` | Версия JDA ниже 6. В `pom.xml` должна быть `net.dv8tion:JDA:6.0.0` или новее |
| Кнопка «устарела» | Админу нужно заново нажать «Опубликовать панель» в `/setupvoice` |
